# SUB_ANALYTICS

# Streaming Subscriber Analytics Project

## Objective
This project analyzes streaming subscription behavior using public proxy datasets to model subscriber growth, ARPU, churn, retention, and revenue forecasting.

## Business Context
Streaming platforms such as Disney+, Netflix, and Max rely on subscriber analytics to evaluate growth, monetization, retention, and international expansion strategy.

## Key Questions
1. Which countries or regions generate the most subscriber revenue?
2. Which subscription plans drive the highest ARPU?
3. How does churn impact subscriber lifetime value?
4. What subscriber growth scenarios improve revenue over time?
5. Which markets show strong growth potential but weaker monetization?

## Planned Analysis
- Data cleaning and schema review
- KPI analysis
- Revenue and ARPU analysis
- Churn and retention modeling
- Cohort analysis
- Forecasting and scenario modeling
